Built for the first hour of a new machine

A new laptop means a dozen setup pages, a few forgotten exports and one command that only works on the author’s machine. These scripts replace that hour with a run you can read first.

  • ReadablePlain bash and PowerShell, no build step, no package to trust. Open the file before you run it.
  • AuditableEach of the fifteen downloads carries a sha256, a line count and the commit it came from.
  • HonestFailures are collected and shown at the end, not swallowed mid run.

What it touches, before you run it

These installers write real files. That is the point, so each one says where it writes and records a failure instead of hiding it.

  • Elevation only where a package manager needs it

    On Linux the Laravel installer calls apt, dnf, pacman or zypper. On macOS it uses Homebrew without sudo. On Windows, winget may ask for an administrator prompt. Setup skills never asks for either.

  • Writes stay where you started

    The skills installer and the Laravel wizard write inside the current folder. The Freebuff script adds one marked block to ~/.zshrc on Linux and macOS, or to $PROFILE on Windows, and replaces that block on later runs.

  • Read it first, then run it

    Every download shows its sha256 and line count. Save it, open it in your editor, compare the hash, then run it with bash.

Questions before a run

Do I need sudo or admin rights?

It depends on the platform. Linux uses sudo for PHP, database and helper packages. macOS uses Homebrew and never calls sudo. Windows may show an administrator prompt when winget installs PHP, Ollama or the database. Setup skills and Freebuff never ask for either.

Which systems are supported?

Every script ships in three versions: bash for Linux, bash for macOS, and PowerShell for Windows 10 and 11. Package installs cover apt, dnf, pacman and zypper on Linux, Homebrew on macOS, and winget on Windows. Pick your system above and the downloads follow.

Can I read a script before running it?

Yes, and you should. Download the file, open it in an editor, and compare its sha256 with the hash on this page. The copy command is there for convenience, not to hide the source.

What happens when a step fails?

The run continues where it can, records the failure, and prints a report at the end. Long commands write a log under .design-setup-logs in the folder you ran from.

Will it overwrite my files?

The Laravel wizard creates a new project folder. The skills installer adds files to the current folder and keeps an existing DESIGN.md as DESIGN.md.bak. Freebuff and Claude Code only touch their own marked block in your shell config or, on Windows, their own user variables.

How do I remove what it installed?

Delete the folders and rule files named in the final report. For Freebuff, remove the block between the freebuff markers in ~/.zshrc or $PROFILE. For Claude Code, delete the ANTHROPIC_ exports or user variables. For Laravel, drop the database and delete the project folder.

Why shell scripts and not a package manager?

Bash is already on Linux and macOS, and PowerShell is already on Windows. A script is one file you can read end to end, with no runtime, no registry and no build step. The trade off is that you should read what you run.

Where do the downloads come from?

This site copies them from the repository at build time, hashes each file and serves that exact copy. The footer shows the commit the current downloads came from.
