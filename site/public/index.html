Built for the first hour of a new machine

A new laptop means a dozen setup pages, a few forgotten exports and one command that only works on the author’s machine. These scripts replace that hour with a run you can read first.

  • ReadablePlain bash, no build step, no package to trust. Open the file before you run it.
  • AuditableEach download carries a sha256, a line count and the commit it came from.
  • HonestFailures are collected and shown at the end, not swallowed mid run.

What it touches, before you run it

These installers write real files. That is the point, so each one says where it writes and records a failure instead of hiding it.

  • Root only where a package manager needs it

    The Laravel installer calls apt, dnf, pacman or zypper. The GitHub helper installs figlet and lolcat, and the Claude Code installer adds Node.js when it is missing. Setup skills and Freebuff never ask for sudo.

  • Writes stay where you started

    The skills installer and the Laravel wizard write inside the current folder. The Freebuff script adds one marked block to ~/.zshrc and removes the block it wrote there before.

  • Read it first, then run it

    Every download shows its sha256 and line count. Save it, open it in your editor, compare the hash, then run it with bash.

Questions before a run

Do I need sudo?

Three scripts ask for it. The Laravel installer uses your package manager for PHP and database packages. The GitHub helper installs figlet and lolcat, and the Claude Code installer adds Node.js when it is missing. Setup skills and Freebuff never call sudo.

Which systems are supported?

The scripts target Linux. Package installs cover apt, dnf, pacman and zypper. On macOS, expect to install PHP and your database yourself. On Windows, run them inside WSL.

Can I read a script before running it?

Yes, and you should. Download the file, open it in an editor, and compare its sha256 with the hash on this page. The copy command is there for convenience, not to hide the source.

What happens when a step fails?

The run continues where it can, records the failure, and prints a report at the end. Long commands write a log under .design-setup-logs in the folder you ran from.

Will it overwrite my files?

The Laravel wizard creates a new project folder. The skills installer adds files to the current folder and keeps an existing DESIGN.md as DESIGN.md.bak. The Freebuff and Claude Code scripts append only their own marked export lines to your shell config.

How do I remove what it installed?

Delete the folders and rule files named in the final report. For Freebuff, remove the block between the freebuff markers in ~/.zshrc. For Claude Code, delete the ANTHROPIC_ exports. For Laravel, drop the database and delete the project folder.

Why bash and not a package manager?

Every system has bash. A script is one file you can read end to end, with no runtime, no registry and no build step. The trade off is that you should read what you run.

Where do the downloads come from?

This site copies them from the repository at build time, hashes each file and serves that exact copy. The footer shows the commit the current downloads came from.
