Privacy

This site is a static page and a folder of shell scripts. It sets no cookies, runs no analytics and has no account system.

What the server sees

Like any web server, it receives the request your browser makes: the page or file you asked for, your IP address and your user agent. The included Node server prints method, path and status to its own terminal and writes no log file.

Third parties

The page loads Geist and Geist Mono from Google Fonts, so your browser makes a request to Google when the page opens. If you host this site and want no third party requests, download the fonts and serve them from your own domain.

Downloads

Downloading a script is a plain file request. Nothing about the download is stored by the page, and the scripts themselves make network calls only when you run them.

Contact

There is no contact form. Open an issue in the repository that hosts this site.
